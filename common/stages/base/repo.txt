# log into on a console, reach over ssh, and administer. `nomarchy install base` installs
# these with `pacman -S --needed`; `nomarchy status` reports any that are missing.
#
# Split out of the old common/packages/repo.txt on 2026-09-27, which had been curated from
# caesar's `pacman -Qqe` on 2026-09-13. Hardware and role belong in hosts/<host>/packages/.
