# Mod+M runs common/scripts/spotify-limited, which wraps spotify-LAUNCHER, not `spotify`.
# Arch ships the launcher in [extra] and it fetches the real binary into
# ~/.local/share/spotify-launcher/ on first run, so the AUR `spotify` package is not wanted
# here and would be a second copy. The launched processes still report as `spotify`, which
# is what the script's already-running guard and the Mod+M window match both key on.
spotify-launcher
