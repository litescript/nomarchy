# Stage `desktop`, AUR. Built by `nomarchy install` in ~/builds/<pkg> with makepkg -- the
# layout umbriel-update relies on -- in the order listed, so a package that depends on
# another AUR package must come after it.
#
# paru is here because Pete uses it by hand; the installer deliberately does NOT use it:
# paru builds in ~/.cache/paru/clone, and umbriel-update expects ~/builds/umbriel-git. It
# sits in THIS stage, not base, because it builds with cargo: in base, makepkg -s would
# install Arch's `rust` for cargo, which then conflicts with this stage's rustup. The
# installer sets rustup's default toolchain before the first AUR build (toolchain_step).
#
# Deliberately NOT listed: umbriel-git-debug and xdg-desktop-portal-umbriel-git-debug.
# Those are makepkg byproducts that arrive alongside the real package when debug packaging
# is enabled; they show up in `pacman -Qqe` but must not be installed on their own.
#
# umbriel-git and its portal are built at the revs pinned in common/umbriel/UPSTREAM, never
# at upstream main (see aur_build in common/scripts/nomarchy). After the first install they
# are updated by `umbriel-update`, never by rebuilding them here: that script gates the new
# binary against the live config before installing it, and only then moves the pins.

# umbriel-git DEPENDS on the portal, and makepkg -s cannot fetch an AUR dependency, so the
# portal is built first -- the order umbriel-update's PKGS already uses. The first VM
# rehearsal had them the other way round: 'target not found: xdg-desktop-portal-umbriel-git'.
paru
xdg-desktop-portal-umbriel-git
umbriel-git
herdr-bin
ai-usagebar
# Claude Code and Codex, packaged: the package is the sole install and update owner
# (manifest §8 B2/B3). claude-code's /usr/bin/claude is a wrapper that exports
# DISABLE_UPDATES=1, so Claude's own updater never replaces what pacman installed; the
# check in ./checks catches a native install in ~/.local/bin shadowing it. Their logins
# are private state, migrated, never here.
claude-code
